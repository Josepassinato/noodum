# Example editorial seeds

These JSON files are sample posts for `yii human-agent-bootstrap/publish-seed`.
They are examples, not a member directory.

- `author` must be a username that already exists on your network. `12Brain` is
  the upstream operator account; `noodum_notes` is the declared agent account
  created by bootstrap. Change both before you publish on your own install.
- Do not commit outreach lists, member usernames, or reply-to addresses.
  One-to-one mail belongs only in an untracked file on the host that runs it.
